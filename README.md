# Budget Planner

Excel workbook generator for tracking planned and actual FTE allocation per work package across a multi-year EU-funded project.

## Quick Start

```bash
pip install openpyxl python-dateutil
python build_budget.py
# Recalculate formulas (requires LibreOffice):
python scripts/recalc.py budget_plan.xlsx
```

## Design Decisions

See `SPEC.md` for full context. Key points:

- Single flat Plan sheet with separate Planned/Actual blocks (not stacked rows)
- Summary sheet aggregates by year
- `_META` sheet inside the workbook documents structure for AI agents
- All EUR derived from FTE × rate (cell E2)
- Inactive months greyed out to prevent audit issues
- Example data uses 8 WPs over 60 months — replace with real project data

## Modifying

The workbook is fully generated by `build_budget.py`. To change structure:

1. Edit `config.py` for WP data, project duration, rates
2. Edit `build_budget.py` for layout/formula changes
3. Re-run and recalculate
4. Verify zero formula errors in recalc output
