# Project Overview

## What is Budget Planner?

An openpyxl-based Excel workbook generator for EU-funded (programme) project FTE budget planning. It produces a fully formula-driven `.xlsx` workbook where project managers plan person-month allocations across work packages, track actual EUR spend from accountant reports, and monitor burn rates with automatic RAG status indicators.

## Core Purpose

- **Plan** monthly FTE allocation per person per work package
- **Track** actual EUR expenditure against personnel ceilings
- **Monitor** burn rates, exhaustion projections, and person capacity load
- **Rebuild** workbooks non-destructively after configuration changes (preserving user-entered data)

## Technology Stack

- **Language**: Python 3.10+
- **Core Library**: openpyxl (Excel workbook generation)
- **Date Handling**: python-dateutil
- **Build Tool**: setuptools (via pyproject.toml)
- **Package Manager**: uv
- **Testing**: pytest
- **Recalculation**: LibreOffice (headless, for formula evaluation)

## Key Features

- Two-mode CLI: `init` (fresh workbook from seed data) and `rebuild` (preserve Capacity FTE + Actuals EUR)
- Demo mode (`--demo`) seeds realistic data for WP burn scenarios (OK, OVER, SLOW, WATCH)
- Snapshot/restore for scenario comparison
- Calendar-year column grouping with expand/collapse
- Comprehensive conditional formatting (red/amber/green RAG)
- `_META` sheet with AI-agent-readable documentation
- Font color convention: Blue = input, Black = formula, Green = cross-sheet reference
- All calculated values use Excel formulas, never hardcoded Python values

## Project Structure

```
budget_planner/
  __main__.py        # CLI entry point (init, rebuild, snapshot, restore)
  config.py          # Seed data: WPs, team, demo assignments
  config_sheet.py    # Config sheet builder (params + WP table + roster)
  layout.py          # Centralized column constants and year/month headers
  styles.py          # Font/fill/border constants and style_cell() helper
  plan.py            # Plan sheet: planned FTE block (formulas from Capacity)
  capacity.py        # Capacity sheet: per-person monthly FTE grid
  actuals.py         # Actuals sheet: EUR per WP per month
  summary.py         # Summary sheet: annual aggregation + budget overview
  trends.py          # Trends sheet: burn rate, chart, person load
  meta.py            # _META sheet: AI-readable structural documentation
  reader.py          # Layout detection + data extraction for rebuild
  workbook.py        # Orchestrator: init/rebuild/seed/snapshot/restore
```

## Getting Started

```bash
# Set up dev environment
uv venv && uv pip install -e ".[dev]"

# Create a demo workbook
python -m budget_planner init --demo

# Recalculate formulas (required after generation)
python scripts/recalc.py output/budget_plan.xlsx

# Run tests
pytest tests/ -v
```
